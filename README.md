# Clip Maker

YouTube の切り抜きを「どこを・どの字幕で」だけ決めて作るツール。

## Chrome 拡張（`extension/`）— 拡張だけで切り抜き動画ができる
入れ方: `chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」→ `extension/`

### 使い方
1. YouTube の動画ページで拡張アイコンを押す → ブラウザの横に **パネル** が開く（ページ側をクリックしても閉じない）。
   開いた時点の再生位置が「開始」に入る。動画を動かして「今時間取得」で開始・終了を入れ直せる。
   - 時間は `□:□:□.□`（時・分・秒・コンマ）の 4 つの枠。0 埋めで表示。↑↓ キーでその桁を増減。
   - 開始・終了・長さ（最大 60 秒）は、どれを変えても残りが自動で追随。
2. **「吸い出して編集画面を開く」** → 字幕・コメント・プレビュー用のコマ画像を取って、編集画面のタブが開く。
3. 編集画面
   - **① 切り抜く時間**: 変えたら「この時間で取り直す」。
   - **画面の形**: 横 / 縦（ショート）。縦は「動画の大きさ」「左右の位置」「上下の位置（上・中央・下）」を決める。
     動画が無い所は黒。字幕やコメントはその黒い所にも置ける。
   - **字幕**: 高さと文字の大きさ。**コメント**: 右から左に流れる（半透明）。濃さ・大きさ・高さ・行の数・流れる時間。流さない設定も可。
   - **② 出来上がり**: ▶ で再生すると、時間どおりに字幕・コメント・四角が出る。録画と同じ描画なので、見たままが動画になる。
   - **隠す四角**: 出来上がりの画面の上をドラッグ。いくつでも作れる。掴んで移動・角を掴んで大きさ変更・× で削除。
     ドラッグ中に枠の外へ出ても端で止まり、外で離してもその位置で確定する。
   - **③ 字幕の文**: 行の編集・削除・追加。▶ で YouTube タブがその位置を再生（音声の確認）。
4. **「動画を作る（動画タブに移動します）」** → YouTube タブが前に出て、切り抜く時間を実時間で再生しながら録画する。
   ページの上端に「録画中です。タブ移動しないでください。」と経過時間が出る（動画には入らない）。
   終わると `ダウンロード/clip-maker/clip_<id>_<開始>_yoko.mp4`（縦は `_tate`）ができる。音声つき mp4（H.264 + AAC）。

### 知っておくこと
- 60 秒の切り抜きは録画に約 60 秒かかる。録画中にタブを移動すると映像が止まるので、エラーにして知らせる。
- 画質は再生中の画質まで（YouTube の画質設定を上げてから作ると綺麗になる）。
- 録画中は音が鳴る（ミュートのままだと無音の動画になるため一時的に解除し、終わったら戻す）。
- 字幕は YouTube 側に字幕データ（自動生成を含む）がある動画で取れる。無い動画は「字幕を追加」で手入力。
- コメントは配信アーカイブのチャットのリプレイ（動画の下のコメント欄ではない）。

### 作りのメモ（直すときに読む）
- 描画は `common.js` の `drawClipFrame` の 1 か所。編集画面のプレビューと録画の両方がこれを呼ぶ。
- 「今の動画」の情報と字幕は、ページ側で動く `inject.js` がプレーヤー API から取る。
  ページに埋め込まれた `ytInitialPlayerResponse` は、YouTube 内でページ移動（再読み込みなし）すると前の動画のままなので使わない。
  これを使っていたせいで、字幕のある動画を「字幕なし」と誤判定していた（2026-09-29 に実機で再現して修正）。
- 自動生成字幕は前後の字幕と時間が重なっているので、次の字幕が始まったら前の字幕を終わらせている。
- 隠す四角は元動画の座標（1920×1080 基準）で持つ。縦で動画の大きさや位置を変えると、四角も動画と一緒に動く。
- 録画データは YouTube タブから編集画面へ分割して渡し、拡張のダウンロード機能で保存する
  （ページ側から直接保存すると、2 本目以降が Chrome の「複数ファイルのダウンロード」制限で止まる）。

## PC プロ版（`pro/`・任意。拡張だけで動画は作れるので必須ではない）
```
pip install ./pro          # 要 ffmpeg（PATH）
clipmaker watch            # 常駐: ダウンロード/clip-maker を監視し、拡張で保存すると自動で mp4 に焼き付ける
clipmaker render ダウンロード/clip-maker/<id>_<秒>.clip.json   # 1 本ずつ手動でも可（同名 .srt / .chat.json があれば字幕・チャットを焼き込む）
```
→ 保存した 3 ファイルと同じフォルダに `<id>_<秒>.mp4`（watch）／`out/` 配下（render）。上限 10 分。
- 字幕とチャットは 1 つの `.burn.ass` にまとめて焼く（字幕＝下中央・白文字黒縁、チャット＝指定枠に新しい順で積む。スパチャ金額は黄）。位置・大きさは拡張のプレビューと同じ比率。
- 縦（`frame.mode=portrait`）は 1920×1080 に揃えてマスク → `crop` → 1080×1920 に拡大 → 字幕・チャット、の順。
- `chat_overlay.enabled` なのに chat.json が無いときは黙って字幕だけにせずエラーファイルに書く。
- watch の常駐登録は `pro/watch_downloads.bat` をスタートアップに置く（このリポジトリでは登録済み）。
- 焼き付け失敗は同フォルダの `<base>.render_error.txt` に原因と再実行方法を書く（黙って握りつぶさない）。json を保存し直すと自動で再挑戦。
- 字幕 0 件の srt は「焼くものが無い」として字幕なしで焼く（libass は空 srt を開けず落ちるため明示スキップ）。
- 元動画キャッシュは `ダウンロード/clip-maker/.cache/` に残す（同じ区間の 2 回目以降は数秒で焼ける）。

## 既知のリスク
- YouTube 規約: 切り抜きの公開は元動画の権利者の許諾が要る（ツールはユーザーの責任で使う）。
- 字幕は動画側にトラックがある場合だけ取れる（無い場合はエラー表示。黙って空にしない）。
- Chrome Web Store 審査: `downloads` 権限の用途説明が必要。

## テスト・実機確認
```
cd e2e && npm i
node extension_e2e.js [videoId] [start秒] [length秒]   # 本物の Chrome + YouTube で最初から最後まで通す（窓が開く）。E2E_OK が出れば合格
node check_panel.js                                     # アイコンを押すとパネルが開く設定になっているか
python -m pytest tests -q                               # PC プロ版（pro/）の単体テスト
```
`extension_e2e.js` が確認すること（2026-09-29・v0.8.0 で 24 件すべて合格）:
- 別の動画から YouTube 内の移動で目的の動画へ行っても、字幕とコメントが取れる
- パネル: 開いた時点の再生位置が開始に入る／時間の枠が 4 つで 0 埋め／開始・終了・長さが連動／幅 360 に収まる
- 四角: 複数作れる／枠の外へ引っぱると端で止まる／離した後はついてこない／移動・大きさ変更・× で削除
- プレビューの再生で時間が進む／編集画面で枠からはみ出す所が無い
- 「動画を作る」で横 1920×1080 と縦 1080×1920 の動画ファイルができる／録画中の表示が出て、終わると消える

出来た動画は ffprobe で映像・音声を確認し、コマを画像にして字幕・流れるコメント・四角・縦の黒い所への字幕を目で確認した。
拡張アイコンを実際に押してパネルが開く操作そのものは自動では押せないため、設定値の確認まで（`check_panel.js`）。
