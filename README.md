# Clip Maker

YouTube の切り抜きを「どこを・どの字幕で」だけ決めて作るツール。

## Chrome 拡張（`extension/`）— 拡張だけで切り抜き動画ができる
入れ方: `chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」→ `extension/`

### 使い方
1. YouTube の動画ページで拡張アイコンを押す → ブラウザの横に **パネル** が開く（ページ側をクリックしても閉じない）。
   開いた時点の再生位置が「開始」に入る。動画を動かして「今時間取得」で開始・終了を入れ直せる。
   - 時間は `□:□:□.□`（時・分・秒・コンマ）の 4 つの枠。0 埋めで表示。↑↓ キーでその桁を増減。
   - 開始・終了・長さ（最大 60 秒）は、どれを変えても残りが自動で追随。
   - **字幕**: 「YouTube の字幕」か「音声認識」。音声認識を選ぶと、その場で認識モデル（標準 / 高精度）のダウンロードが始まり、進み具合がパネルに出る
     （画面に出ないページ offscreen.html で行うので、パネルを閉じても止まらない。2 回目以降は保存済みなので一瞬）。
     吸い出しのときに切り抜きの音声も取り込み（切り抜きと同じ時間がかかる）、編集画面でブラウザ内の音声認識（Whisper）にかける。
2. **「吸い出して編集画面を開く」** → 字幕・コメント・プレビュー用のコマ画像を取って、編集画面のタブが開く。
3. 編集画面。左は「設定」「字幕」「コメント一覧」のタブ、右が出来上がり。
   - **設定タブ**
   - **① 切り抜く時間**: 変えたら「この時間で取り直す」。
   - **画面の形**: 横 / 縦（ショート）。縦にすると「元の動画」が出る。黄色い枠は出来上がりと同じ形（9:16 固定）で、枠の中がそのまま出来上がりになる
     （掴んで移動・角で大きさ変更・何も無い所からドラッグで囲み直し）。枠は動画の外まで広げられ、動画の無い所は黒。
     「上下の位置」は 上より・中央・下より・自由。上より/中央/下よりの間は上下の位置がその合わせ方で決まり、大きさを変えても合ったまま。自由にすると上下にも動かせる。
     字幕やコメントは黒い所にも置ける。
   - **音声**: 音あり / 音なし。
   - **画質**: 高（8Mbps）/ 標準（4Mbps）/ 軽い（2Mbps）。出来上がりの目安の大きさを表示する（送り先の容量制限に合わせて選ぶ。例: 60 秒なら 高 ≒ 61MB、標準 ≒ 31MB、軽い ≒ 16MB）。
     エンコードは固定ビットレート（bitrateMode "constant"）。可変だと指定より大きくなり目安と合わなかった（2026-10-09 実測）。
   - **字幕タブ**: 字幕の見た目（高さ・文字の大きさ）と字幕の文。
   - **コメント一覧タブ**: コメントの見た目（右から左に流れる・半透明。濃さ・大きさ・高さ・行の数・流れる時間。流さない設定も可）と、コメントの一覧。
     コメントは時刻・本文を直せて、消す・追加もできる（▶ でそのコメントが出る時刻にプレビューを合わせる）。
   - **② 出来上がり**: ▶ で再生すると YouTube のタブが同じ所を再生し、音声はそちらから鳴る。プレビューの時刻はその再生位置に合わせるので、音を聞きながら字幕を合わせられる
     （映像は 2 秒ごとのコマ送り）。録画と同じ描画なので、見たままが動画になる。
   - **隠す四角**: 出来上がりの画面の上をドラッグ。いくつでも作れる。掴んで移動・角を掴んで大きさ変更・× で削除。
     ドラッグ中に枠の外へ出ても端で止まり、外で離してもその位置で確定する。
   - **字幕の文**: 行の編集・削除・追加。▶ で YouTube タブがその位置を再生（音声の確認）。
     「音声認識で字幕を作り直す」で、音声認識の字幕に置き換えられる（音声がまだ無ければ YouTube のタブで取り込む）。モデルは 標準 / 高精度。
4. **「動画を作る（動画タブに移動します）」** → YouTube タブが前に出て、切り抜く時間を実時間で再生しながら録画する。
   ページの上端に「録画中です。タブ移動しないでください。」と経過時間が出る（動画には入らない）。
   終わると `ダウンロード/clip-maker/` に mp4（H.264 + AAC）ができる。
   ファイル名は `作った日時_縦横_音の有無`。例: `20261004_153045_short_sound_off.mp4`（横は `horizon`、音ありは `sound_on`）。

### 知っておくこと
- 60 秒の切り抜きは録画に約 60 秒かかる。録画中にタブを移動すると映像が止まるので、エラーにして知らせる。
- 画質は再生中の画質まで（YouTube の画質設定を上げてから作ると綺麗になる）。
- 録画中は音が鳴る（ミュートのままだと無音の動画になるため一時的に解除し、終わったら戻す）。
- 字幕は YouTube 側に字幕データ（自動生成を含む）がある動画で取れる。無い動画は「字幕を追加」で手入力。
- コメントは配信アーカイブのチャットのリプレイ（動画の下のコメント欄ではない）。
- 音声認識は拡張の中（`asr-worker.js` + `vendor/transformers.js` + onnxruntime の wasm）で動く。PC 側に何も入れない。
  `vendor/transformers.js` は配布物そのまま（@huggingface/transformers 4.3.0 の dist/transformers.js）だが 1 か所だけ文字列を分割してある（"Mistral3ForConditionalGeneration" を GitHub の秘密情報検査が API キーと誤検出して push を拒むため。値は同じ）。差し替えるときは同じ処置をする。
  認識モデルは初回に Hugging Face からダウンロードしてブラウザ（Cache API の `transformers-cache`）に保存する（標準 = whisper-small 約 393MB、高精度 = whisper-large-v3-turbo 約 560MB）。
  保存済みのモデルを読み込むときも同じ進み具合の通知が来るため、以前は毎回「ダウンロード中」と表示されていた（2026-10-08 ユーザー指摘）。
  今は asr.js の asrCached で保存済みかを先に調べ、「保存済みの認識モデルを読み込み中」と表示を分ける。
  GPU（WebGPU）が使えれば GPU、無ければ CPU。実測（RTX 2060・14 秒の音声）: 標準 GPU 7 秒 / 高精度 GPU 6 秒（初回は +ダウンロード・準備で 40〜80 秒）/ 標準 CPU 47 秒（初回）。
  無音や音楽だけの区間に対して Whisper は「チャンネル登録お願いします!」のような作り話を出す（EnCGw7fSZq0 の 0:03〜 で実測）。
  音量（RMS < 0.01）の小さい区間と、決まり文句だけの行は捨てる（asr.js の audioLevel / looksHallucinated）。
  「長い区間に短い文しか無い行」を捨てる規則は、話し声の行まで消したので入れていない。Whisper の結果は同じ音声でも回によって行の切り方が変わる。
  精度は話し方しだい。この配信の例では YouTube の自動字幕と同程度で、固有名詞（配信者の挨拶など）はどちらも誤る。句読点と行の区切りは音声認識の方が自然。

### 作りのメモ（直すときに読む）
- **ファイルを直したら `manifest.json` の version と `common.js` の BUILD を同じ値に上げる。**
  Chrome は YouTube のタブで動く部品（content.js など）と manifest を「拡張を読み込んだ時点」で覚え、`chrome://extensions` の更新ボタンを押すまで使い続ける
  （タブを読み込み直しても変わらない）。パネルと編集画面は開くたびに最新のファイルを読むので、更新ボタンを押していないと新しい画面が古い部品に命令することになる。
  2026-10-04 にこれで「再生が止まらない・囲み枠が効かない・音なしが効かない」が起きた。
  今は、画面が読んだ BUILD と Chrome が覚えている version が違えば、画面に「拡張を更新する」ボタンを出し、ほかのボタンを押せなくする（押すと拡張が自分で読み込み直される）。
- 描画は `common.js` の `drawClipFrame` の 1 か所。編集画面のプレビューと録画の両方がこれを呼ぶ。
- 「今の動画」の情報と字幕は、ページ側で動く `inject.js` がプレーヤー API から取る。
  ページに埋め込まれた `ytInitialPlayerResponse` は、YouTube 内でページ移動（再読み込みなし）すると前の動画のままなので使わない。
  これを使っていたせいで、字幕のある動画を「字幕なし」と誤判定していた（2026-09-29 に実機で再現して修正）。
- 自動生成字幕は前後の字幕と時間が重なっているので、次の字幕が始まったら前の字幕を終わらせている。
- 隠す四角は元動画の座標（1920×1080 基準）で持つ。縦で動画の大きさや位置を変えると、四角も動画と一緒に動く。
- 録画は WebCodecs（VideoEncoder / AudioEncoder）で、動画の新しいコマが出るたび（`requestVideoFrameCallback`）に 1 枚描いて、
  元動画の時刻をそのままコマの時刻にしてエンコードする。mp4 は `mp4.js` で自前で組み立てる（ふつうの mp4。断片化しない）。
  読み込み待ちで再生が止まったぶんは映像の時刻を遅らせて音声と合わせる（content.js の stall）。
  `e2e/check_smooth.py` で測った値（同じ 14 秒・30 コマ/秒の動画）:
  MediaRecorder 一定間隔 = 約 26 コマ/秒・50ms 超の間隔 53〜91 回 → MediaRecorder コマごと = 約 29.8 コマ/秒・8〜21 回 → WebCodecs = 30.0 コマ/秒・0 回（全コマ 33.3ms ちょうど）。
  WebCodecs が使えないブラウザでは MediaRecorder に戻り、その旨を画面に出す。
- 動画側のコマの通知が 1 回飛ぶと 1 コマぶん間隔が空くので、直前のコマを同じ間隔で入れて埋める（content.js の frameDur / lastFrame）。
- 録画データは YouTube タブから編集画面へ分割して渡し、拡張のダウンロード機能で保存する
  （ページ側から直接保存すると、2 本目以降が Chrome の「複数ファイルのダウンロード」制限で止まる）。

## PC プロ版（`pro/`・任意。拡張だけで動画は作れるので必須ではない）
```
pip install ./pro          # 要 ffmpeg（PATH）
clipmaker watch            # 常駐: ダウンロード/clip-maker を監視し、拡張で保存すると自動で mp4 に焼き付ける
clipmaker render ダウンロード/clip-maker/<id>_<秒>.clip.json   # 1 本ずつ手動でも可（同名 .srt / .chat.json があれば字幕・チャットを焼き込む）
```
→ 保存した 3 ファイルと同じフォルダに `<id>_<秒>.mp4`（watch）／`out/` 配下（render）。上限 10 分。
- 字幕とチャットは 1 つの `.burn.ass` にまとめて焼く（字幕＝下中央・白文字黒縁、チャット＝指定枠に新しい順で積む。スパチャ金額は黄）。位置・大きさは拡張のプレビューと同じ比率。
- 縦（`frame.mode=portrait`）は 1920×1080 に揃えてマスク → `crop` → 1080×1920 に拡大 → 字幕・チャット、の順。
- `chat_overlay.enabled` なのに chat.json が無いときは黙って字幕だけにせずエラーファイルに書く。
- watch の常駐登録は `pro/watch_downloads.bat` をスタートアップに置く（このリポジトリでは登録済み）。
- 焼き付け失敗は同フォルダの `<base>.render_error.txt` に原因と再実行方法を書く（黙って握りつぶさない）。json を保存し直すと自動で再挑戦。
- 字幕 0 件の srt は「焼くものが無い」として字幕なしで焼く（libass は空 srt を開けず落ちるため明示スキップ）。
- 元動画キャッシュは `ダウンロード/clip-maker/.cache/` に残す（同じ区間の 2 回目以降は数秒で焼ける）。

## 既知のリスク
- YouTube 規約: 切り抜きの公開は元動画の権利者の許諾が要る（ツールはユーザーの責任で使う）。
- 字幕は動画側にトラックがある場合だけ取れる（無い場合はエラー表示。黙って空にしない）。
- Chrome Web Store 審査: `downloads` 権限の用途説明が必要。

## テスト・実機確認
```
cd e2e && npm i
node extension_e2e.js [videoId] [start秒] [length秒]   # 本物の Chrome + YouTube で最初から最後まで通す（窓が開く）。E2E_OK が出れば合格
node check_panel.js                                     # アイコンを押すとパネルが開く設定になっているか
node asr_e2e.js [videoId] [start秒] [length秒] [small|turbo] [wasm]   # 音声認識: 取り込み → 認識 → 字幕に入るまで（モデルは e2e/.profile に保存される）
   PROFILE=別フォルダ node asr_e2e.js ...                        # 「初回」（モデル未取得）の状態から確認する
node shots_for_hp.js <videoId> <start秒> <length秒> [出力先]  # HP 用のスクリーンショット（自分の動画で撮る。既定の出力先は ../chatani-moka-site/img/clip-maker）
python -m pytest tests -q                               # PC プロ版（pro/）の単体テスト
```
`python e2e/check_smooth.py <動画>` で、出来た動画のコマ数・コマの間隔・音声の有無を数値で見られる。

`extension_e2e.js` が確認すること（2026-10-05・v0.11.0 で 42 件すべて合格。作った動画はテストの最後に自分で消す。残すなら `KEEP=1`）:
- 拡張が古いままのとき（ファイルだけ新しい）: 案内と「拡張を更新する」ボタンが出て、ほかのボタンは押せない
- 別の動画から YouTube 内の移動で目的の動画へ行っても、字幕とコメントが取れる
- パネル: 開いた時点の再生位置が開始に入る／時間の枠が 4 つで 0 埋め／開始・終了・長さが連動／幅 360 に収まる
- 四角: 複数作れる／枠の外へ引っぱると端で止まる／離した後はついてこない／移動・大きさ変更・× で削除
- プレビューの再生で時間が進み、YouTube のタブが同じ所を再生している（音声）／止めると YouTube 側も止まる／終わりまで行くと終了の位置で止まる
- 編集画面で枠からはみ出す所が無い
- 縦: 最初の枠は 9:16 で中央／大きさを変えても 9:16 のまま／掴んで移動できる／下よりで動画の下端と枠の下端がそろい、上が黒になる
- 「動画を作る」で横（音あり）と縦（音なし）の動画ファイルができる／ファイル名が 日時_縦横_音の有無／録画中の表示が出て、終わると消える
- 出来た動画そのもの: 音ありには音声が入っている／音なしには入っていない／縦は囲み枠どおりに切り取られている／コマの間隔が揃っている（50ms 超の間隔なし）／WebCodecs で録画できた

出来た動画は ffprobe で映像・音声を確認し、コマを画像にして字幕・流れるコメント・四角・縦の黒い所への字幕を目で確認した。
拡張アイコンを実際に押してパネルが開く操作そのものは自動では押せないため、設定値の確認まで（`check_panel.js`）。
