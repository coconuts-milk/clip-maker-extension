# Chrome Web Store 掲載情報（コピペ用）

## 名前
Clip Maker — YouTube 切り抜き

## 概要（132 文字以内）
見ている YouTube の場面（最長 60 秒）を、字幕・コメント・隠し四角つきの切り抜き動画にします。横と縦（ショート）に対応。拡張機能だけで mp4 ができます。

## 詳細説明
見ている YouTube 動画の「今のこの場面」を、そのまま切り抜き動画（mp4）にする拡張機能です。PC に別のソフトを入れる必要はありません。

できること:
- 開始・終了・長さを決めて（最長 60 秒）、字幕・コメント・プレビューを取り込む
- 横（1920×1080）と縦（ショート 1080×1920）。縦は元の動画のどこを使うかを枠で囲んで決める
- 字幕: YouTube の字幕をそのまま使うか、ブラウザ内の音声認識で作る。文は自由に直せる
- コメント: 配信アーカイブのチャットのリプレイを右から左に流す（載せない設定も可）
- 隠したい所を四角で覆う（複数可）
- 音あり / 音なし
- 出来上がりを再生して確認してから「動画を作る」。再生中の映像と音声をブラウザ内で録画して、ダウンロードフォルダに mp4 を保存

できないこと（正直に書きます）:
- 動画ファイルを直接ダウンロードする機能ではありません。切り抜く時間のぶんだけ再生しながら録画します（60 秒の切り抜きは約 60 秒）
- 字幕は、YouTube 側に字幕がある動画か、音声認識を使う場合に作れます
- コメントは、チャットのリプレイがある動画（配信アーカイブなど）だけ取れます
- 音声認識は初回に認識モデル（数百 MB）をダウンロードします。GPU（WebGPU）が使える PC では速く、無い PC では時間がかかります

切り抜き動画の公開には元動画の権利者の許諾が必要です。本拡張はデータ整理と編集を助けるツールであり、利用はユーザーの責任で行ってください。

## 権限の用途説明（審査フォームに貼る）
- activeTab / scripting / host (youtube.com): 開いている YouTube の動画ページから再生位置・字幕・チャットのリプレイを読み取り、再生中の映像と音声をブラウザ内で録画するためだけに使用します。
- downloads: 作成した切り抜き動画をユーザーのダウンロードフォルダ（clip-maker/）に保存するためだけに使用します。
- storage / unlimitedStorage: 編集中の下書き（取り込んだ字幕・コメント・プレビュー画像・音声認識用の音声）と、設定（長さ、字幕の作り方など）の保存に使用します。外部送信はしません。
- sidePanel: 拡張アイコンを押したときに開く操作パネルの表示に使用します（動画を操作しながら時間を決めるため、ページをクリックしても閉じないパネルにしています）。
- content_security_policy の 'wasm-unsafe-eval': 音声認識（同梱の onnxruntime の WebAssembly）を動かすために必要です。
- リモートコード: 使用しません。全コードはパッケージ内です。音声認識の認識モデル（データ）だけを Hugging Face から初回にダウンロードします。

## 単一用途の説明
YouTube の動画の一部分を、字幕・コメントつきの切り抜き動画として保存する。

## 公開範囲（少人数で試してもらうとき）
- 「限定公開」: ストアの検索には出ず、URL を知っている人だけがインストールできる。審査はある。
- 「非公開（テスター）」: 指定した Google アカウント（または Google グループ）だけがインストールできる。審査はある。
- 審査には数日かかることがある。すぐ試してもらうなら、`python store/make_assets.py` が作る zip を渡して「パッケージ化されていない拡張機能を読み込む」で入れてもらう。
