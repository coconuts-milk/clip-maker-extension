# Chrome Web Store 掲載情報（コピペ用）

## 名前
Clip Maker — YouTube 切り抜きメモ

## 概要（132 文字以内）
YouTube の見ている場面から最大 30 秒分の「切り抜きメモ」（時間・字幕・表示中コメント）を 3 つのファイルに保存。字幕と時間は後からテキスト編集できます。

## 詳細説明
見ている YouTube 動画の「今のこの場面」を、切り抜き作業に使えるデータとして保存する拡張機能です。

保存されるもの（ダウンロード/clip-maker/ に 3 ファイル）:
- clip.json … 動画 ID と開始・終了秒。メモ帳で書き換えて区間を調整できます
- srt … その区間の字幕。メモ帳で書き換えれば字幕を編集できます
- comments.json … 画面に表示されていたコメント

できないこと（正直に書きます）:
- 動画ファイル自体のダウンロードはしません
- 字幕トラックの無い動画では字幕は取れません（その旨を表示します）
- コメントは画面に読み込まれた分だけです

切り抜き動画の公開には元動画の権利者の許諾が必要です。本拡張はデータ整理を助けるツールであり、利用はユーザーの責任で行ってください。

## カテゴリ
仕事効率化 / ツール

## 権限の用途説明（審査フォームに貼る）
- downloads: 取得した切り抜きメモ（clip.json / srt / comments.json）をユーザーのダウンロードフォルダに保存するためだけに使用します。
- activeTab / host (youtube.com): 開いている YouTube 再生ページから再生位置・字幕・表示中コメントを読み取るためだけに使用します。
- storage: 現在未使用（将来の設定保存用）。審査で指摘されたら manifest から外す。
- リモートコード: 使用しません。全コードはパッケージ内です。
